# 给朋友办一场小型放映会

## Destination

找到一个让朋友愿意留下来聊几句的放映会方案。明确想传达的感受、影片与开场方式，就可以开始准备。

## Notes

这是用于试用 Beacon 的虚构情境，不代表真实活动安排。只探索决定，不执行活动。所有成果都保存在当前目录，使用本地 Markdown tracker。
