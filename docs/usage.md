# Waygoal 简明使用指南

**先在右侧聊，需要时在左侧分叉，再把有用的发现带回来。**

## 1. 开始一张画布

在仓库根目录执行 `npm run setup`（首次安装）和 `npm run dev`，打开 [Waygoal](http://127.0.0.1:30142/waygoal)。

点击左上角「工作目录 / 画布」：

- **切换工作目录**：选择这次工作的文件夹。
- **＋ 新建**：建立空画布，写下第一句并发送后，画布和第一张卡片出现。
- **加入已有会话**：把当前目录中的旧会话移入这张画布，完整历史保留。尚未归类的会话可在「未归类会话」里找到。

新建画布只是整理空间，实际调用模型从发送消息开始。

## 2. 像普通聊天一样继续

一直在右侧输入即可，左侧会随对话增加轮次卡片。会话可以在同一张画布里展开、收起，多段讨论可以一起看。

点击会话或轮次卡片，右侧直接打开对应聊天并定位原文；切换回来时，各会话的草稿仍在。聊天里的「定位卡片」及快捷节点可以返回画布位置。

点击旧分支的轮次，也在右侧阅读历史，原输入框暂时隐藏并保留草稿。点击「返回当前聊天」恢复输入；明确点击「切换到这条分支」才会改变 Pi 的继续位置。普通切换会话不会把历史倒退到所点轮次。

找不到当前位置时，点左下角「回到正在聊的位置」；想看整体，点「看全局」，或使用右下角缩略图。

## 3. 从一个问题分出去

在右侧某条消息旁，或左侧轮次卡片的操作条中，点 **「从这里分叉」**。

- 从消息分叉：新会话保留截至这条消息的历史。
- 从轮次卡片分叉：保留截至这一轮结束的历史。
- 所选位置之后的讨论不会带过去；新会话可以沿另一方向继续。

同源历史在画布上共用一份，分支从真实节点接出。还没有新消息的分支先以会话标题呈现，继续发送后再长出新卡片。

如果要在同一会话里换一条已有路径继续，用 **「••• → 选择继续路径」**；这里只回看时不切换，明确选择继续才切换。

## 4. 把发现带回另一段讨论

先打开要接收材料的会话，再选另一分支的卡片：

1. 点 **「引用回答」**；或在「••• → 引用连线」中选择来源卡片的连线点，再点「下一轮」。
2. 查看输入框上方的材料，核对引用范围和原文；不需要的可以移除。
3. 写下你想继续讨论的问题，发送。

例如：把「观影方案」和「桌游方案」各自的发现带回，问“根据人数和预算，哪一种更合适？”

**想把两轮相关的想法留在一起回看：** 在卡片上点「关联讨论」，再点另一张卡片即可。鼠标移到卡片或用键盘聚焦时会出现入口，触屏直接显示。来源卡片会标出「关联起点」，目标会提示「关联到这里」。点保存后的连线，可以回看两轮或移除关联。

例如：把先前提出的需求与另一段讨论中的解决思路连起来，之后方便对照。

**「关联讨论」只作回看标记；「引用回答」才把内容带给下一轮模型。**

## 5. 留下值得记住的一句话

点击轮次卡片的 **「所得」**，写下发现、待解问题或认可的方向。也可以点「请 Pi 提炼」，检查文字后「确认并保存」。

这句话只帮助你读画布，不改聊天原文，也不会自动加入下一轮材料。

## 常用小操作

| 操作 | 入口 |
| --- | --- |
| 平移、缩放 | 拖动画布空白处、滚轮；画布获得焦点时可用方向键、`+` / `-`，`0` 看全局 |
| 调整聊天框大小 | 桌面布局中拖动左侧、顶部或角上的调节柄；双击调节柄恢复默认 |
| 改会话名 | 聊天标题旁「••• → 改名」或「请 Pi 起个名字」 |
| 查找、分组、整理位置 | 顶部菜单「查看会话与票据」；⌘/Ctrl 点选多张卡片后操作 |
| 新开独立讨论 | 顶部「新开聊天」 |
| 使用技能 | 输入 `/skill:名称`，例如调用自己已安装的研究或写作技能 |

有票据时，可以从票据开始讨论，或返回查看来源与依赖。日常探索直接聊天即可。
