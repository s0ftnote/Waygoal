# 连续对话驱动画布生长，卡片引用保留真实来源

Waygoal 以持续存在的 pi-web 对话为基础，右侧展示当前路径的完整历史并连续输入，左侧把已有对话呈现为精简轮次卡片。卡片和快捷节点导航双向定位；纯查看不切换活动路径，不重建聊天框或丢失草稿。用户已明确否定“每张卡片一个聊天入口、聊一轮再选择下一张”的方案，原因是它打断正常思考与聊天。

Pi session 承载会话树，消息记录以 parentId 连接；轮次卡片只是对真实历史的展示，不为每轮创建 session。Tree 路径选择和分叉是明确改变继续路线的操作。产品沿用 [ADR 0005](0005-keep-pi-web-session-hosting.md) 的运行方式，本决定不改变 Pi 的单父节点历史结构。

在 [ADR 0003](0003-discussion-and-ticket-map.md) 的会话与可选票据关系上，增加用户明确选择的材料引用：手动连线可选取其他卡片的内容用于下一轮，并保留来源与范围。它与只作整理的手动关联分别呈现；引用不改写旧历史，发送仍由用户发起。代价是产品需要分别保存历史来源、材料引用和当前继续位置，不能把所有连线或选中状态解释为同一件事。具体交互和原型验证见[画布导航与状态](../design/canvas-navigation-and-states.md)。
