# 澄清讨论可独立于票据地图

普通澄清可以在没有 Wayfinder 地图、没有票据的情况下进行，沿用 Pi 聊天；总画布呈现会话与真实分叉，Wayfinder 地图组织跨会话的独立探索。画布负责整体关系、导航和状态，轻量说明帮助用户理解方法。用户在后续讨论中撤回了将 grilling 转为问题卡或可操作草图的方向；这些展示不分析聊天内容，也不向会话注入内容或干预提问。

Grilling 的决策树随回答变化，表达 Agent 对问题前提的判断；它不等同于 tracker 中的票据依赖图。追问、选项和一轮问答不自动建票，也不自动新开会话。进入 Wayfinder 后，按其方法为能够明确表述的独立问题建票，包括已明确但被阻塞的问题；尚无法明确的问题留在地图的未明确方向中。这样的边界避免为获得可视化而制造大量票据，代价是界面需要清楚区分讨论内容与正式工作记录。

票据节点关联正式票据，创建票据与创建会话是不同动作；进入时按需创建或恢复相关会话。分支来源保留讨论从哪里产生、为什么分出及返回后要继续的问题；依赖表达完成所需的前提。地图允许多个前提和分支汇合，阻塞不禁止补充讨论。独立探索完成后更新原票据与地图，需要返回时把有依据的结论交给等待它的讨论，不强制返回根会话。地图探索完成后仍需汇总关联结论，形成行动依据，再按需要拆解与验证。

讨论由 Pi 会话承载；正式票据及结论继续遵循 [ADR 0001](0001-tracker-authority-and-local-canvas-records.md) 的来源边界和 [ADR 0002](0002-faithful-preview-and-full-view.md) 的原文展示原则，不要求改动 Matt 的票据格式。分支返回的明确上下文交接仍是独立的工作流能力；缩略图导航、提示出现和状态刷新不触发它。

有票据时，画布按“票据 → 关联会话 → 真实讨论分支”组织：票据是上层工作单元，会话承载围绕它展开的讨论。同一张票据可以关联多个会话及分支；画布保留一张票据，展开后进入下层讨论。无票据的会话仍可独立留在总画布。分叉不复制票据，也不新增 tracker 阻塞关系；只有来源中实际创建新票时才登记新的票据节点。

票据关联、票据依赖与会话分叉来源是三种不同关系。选择以票据组织相关讨论，使用户能从待解决的问题进入会话，同时保留独立会话的自由；代价是界面必须区分工作层级与讨论路径。关联不合并上下文，不改变 Pi 的会话存储或分叉语义，也不意味着删除票据时删除聊天历史。挂出或收起只是同一会话的展示变化，具体布局与用户确认记录放在[画布导航与状态](../design/canvas-navigation-and-states.md)。

## 验证边界

当前展示方向见[画布导航与状态](../design/canvas-navigation-and-states.md)。观察用户能否找到当前位置、区分等待与解锁、回看已有结论，以及关闭提示后正常继续聊天。分支返回仍需验证用户是否无需复述上下文；研究中的建议见[工作流研究](../research/matt-workflow-guidance.md)，其中问题卡等历史提案已撤回。

当前主原型仍从根入口固定调用 Wayfinder，以票据卡和聊天面板为主，并限制未关联会话的阻塞/已解决票据开始聊天；这些是接入实验的现状，不是本决定要求的产品行为。用户主动选择技能的入口、分支交接和完整流程承接尚待实现与验证。技能选择遵循 [ADR 0004](0004-canvas-carrier-and-user-chosen-skills.md)，产品不主动路由。
