# 统一为独立的 Waygoal 应用结构

日期：2026-09-21。状态：已接受。

## 问题

仓库根目录以 Waygoal 为入口，`apps/web` 内却仍包含完整 pi-web 包、说明和发布命令；源码按 components、hooks、lib 平铺，同一功能需要跨多个目录寻找。用户要求将其作为自己的产品维护并重新整理结构。

## 决定

保留一个根目录应用包和锁文件，使用 `src/app` 承载 Next.js 路由，`src/features` 按功能组织前端与纯计算代码，`src/server` 管理 Pi 运行、文件与外部接入，`src/shared` 保存跨功能基础代码。单元测试跟随实现，浏览器回归放在 `tests/e2e`。

Waygoal 成为默认入口，原完整聊天与设置界面位于 `/chat`；已有 `/waygoal` 和 `/api/*` 地址保留。项目版本与发布信息独立，不再查询或推荐 pi-web npm 更新。上游版权和历史资料保留。

本决定调整代码所有权和目录组织，不改变 ADR 0005 中 Pi AgentSession 进程内运行的决定，也不更换会话格式、用户数据目录或已有配置键。根目录命令是新的开发入口，其他机器需从仓库根目录重新安装依赖。

## 验证

迁移后执行静态检查、完整单元测试、生产构建及隔离数据的会话、分叉、票据和面板浏览器回归。构建在独立 checkout 中运行，避免影响正在使用的开发服务。
