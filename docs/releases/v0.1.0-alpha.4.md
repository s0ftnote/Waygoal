# Waygoal v0.1.0-alpha.4

2026-09-18。源码预发布版本，重点完善画布探索、连续聊天与独立文件阅读。Waygoal 的版本记录在根目录 package.json；apps/web 继续保留复用宿主的包名及版本。

## 本版变化

- 新增独立文件阅读区：左侧切换画布和文件，宽屏右侧保持连续聊天；支持文件标签、收起恢复、放大阅读、分栏宽度调节与各文件阅读位置记忆，窄屏采用单区阅读。
- 本地 Markdown 文件链接进入应用内预览，修复点击报告后跳到 404 的问题；文件阅读沿用宿主路径解析与访问边界。
- 新会话输入框沉底，统一输入区左右边距；调整面板大小的焦点提示缩到小把手，去除贯穿面板的长边框。
- 支持从已保存回答选文并分叉探索；支持多选轮次、冻结引用材料后继续综合，保留原讨论、草稿与来源。
- 材料托盘展示来源、范围和原文，提供只读回源；补齐延迟响应、发送确认、分叉失败恢复、提前打开新分叉及工作区切换的竞态保护。
- 统一会话收放与轮次画布，加入轮次所得、语义缩放和同源分叉历史展示；完善画布定位、拖拽接手与操作成功后的空间反馈。

## 运行

需要 Node.js 24。当前提供源码运行，尚无独立安装包。

```sh
git clone --branch v0.1.0-alpha.4 https://github.com/s0ftnote/Waygoal.git
cd Waygoal
npm run setup
npm run build
npm start
```

打开 http://127.0.0.1:30142/waygoal 。开发时使用 npm run dev；构建前停止同一目录的开发服务。默认沿用本机 Pi 配置；自动检查使用隔离 Pi 数据与可控假模型。

## 验证与边界

- Node.js 24 下，lint（零错误）、类型检查、1,147 项单元测试及生产构建通过。
- 14 组共 375 项浏览器检查通过，覆盖连续聊天、分叉、票据、工作区、独立文件阅读、所得、选文探索和竞态恢复；窄屏菜单遮挡已修复。
- 已实测独立文件区的标签切换、收起恢复、宽度调节、放大阅读、窄屏布局，以及聊天草稿和阅读位置保持不变。

- 文件标签及阅读位置保留在当前页面内存中，尚不保证刷新恢复；文件树和最近文件侧栏不包含在本版。
- 未发送草稿及材料不承诺跨刷新恢复；已发送引用随真实 Pi 消息保存。
- 浏览器自动检查使用真实 Pi SDK 与可控假模型，不代替真实模型供应商、长时间使用或真机触屏验收。
- 不包含正文搜索、PDF 阅读闭环、来源版本比较或自动重跑下游流程。
