# Waygoal v0.1.0-alpha.3

2026-09-15。首个源码预发布版本，接入已确认的连续聊天与轮次画布交互。Waygoal 的版本记录在根目录 package.json；apps/web 保留复用宿主的包名及版本。

## 本版变化

- 浏览器回归等待预览正文加载，并按来源消息选择分叉按钮，适配同一窗口中多个分叉入口。

- 修正 641–767px 窗口宽度下聊天面板未铺满宽度的问题，使嵌入预览和窄屏采用一致的上下布局。

- 连续发送沿用同一个聊天窗口，查看和移动卡片保留输入框、草稿与消息位置。
- 轮次使用真实 Pi session ID 与 entry ID。卡片、历史消息和快捷导航可以互相定位；长历史支持跨多页读取。
- 其他路径在画布内只读预览。Tree 与消息编辑共用明确的路径切换入口，保存并恢复各路径文字、图片和引用草稿。
- 用户消息和助手消息按各自边界创建真实 Pi 分叉；第一条回答前的空分叉也可继续发送。
- 文字材料在选择时冻结，审阅内容与实际 prompt 一致，保留来源身份；路径切换会取消过期材料读取。

## 运行

需要 Node.js 24。当前以源码运行，尚无独立安装包。

```sh
git clone --branch v0.1.0-alpha.3 https://github.com/s0ftnote/Waygoal.git
cd Waygoal
npm run setup
npm run build
npm start
```

打开 http://127.0.0.1:30142/waygoal 。开发时使用 npm run dev；构建前应停止同一目录的开发服务。默认沿用本机 Pi 配置；演示和自动检查使用隔离的 PI_CODING_AGENT_DIR。

## 验证与限制

- Node.js 24.21.0、Pi SDK 0.85.1 下，1,101 项单元测试、10 组共 248 项浏览器检查及生产构建通过。
- 浏览器验证使用真实 Pi SDK 与可控假模型，真实模型供应商和日常使用体验尚未验收。
- 材料范围为文字，不包含图片、思考内容和工具调用参数。未发送草稿仅保存在浏览器内存，刷新后的草稿恢复不在本版保证范围内。
- 原有总画布的地图提示可能遮住其他卡片。键盘聚焦后按 Enter，以及票据面板入口可用；该布局问题仍保留。
- 超大树的虚拟化和视觉参数需要继续打磨。

完整证据及范围见[接入验证记录](../research/turn-cards-integration-results.md)。
