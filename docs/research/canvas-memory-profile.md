# 长会话画布内存复测

2026-09-22，基线为 `0d2f2ac`，优化为本次视野裁剪改动。

## 场景与测量

生产构建，1440 × 900 浏览器视口；临时 Pi 数据包含 8 个会话，每个 200 轮，每轮带约 12 KB 工具结果和一段长回复。依次打开全部会话，再关闭聊天面板。浏览器与服务端均在强制 GC 后取样，使用相同脚本与数据规模；没有访问真实会话或发送模型请求。

关闭面板后的比较：

| 指标 | 基线 | 优化后 |
| --- | ---: | ---: |
| 页面 JS 堆（MiB） | 30.11 | 22.69 |
| DOM 节点 | 26,109 | 4,124 |
| 事件监听器 | 3,719 | 580 |
| 挂载的轮次卡片 | 1,600 | 16 |
| 远离视野的卡片 | 1,564 | 0 |
| 服务进程 JS 堆（MiB） | 81.41 | 81.70 |

这轮主要减少屏幕外的卡片与连线 DOM。服务端内存在该场景中接近。浏览器进程总内存、开发编译器开销和长期运行后的变化需要分别测量；单次 GC 后的堆大小会有波动，因此回归门槛检查离屏 DOM 和操作结果。

全景仍保留完整场景：优化后全景显示全部 1,600 张卡片，页面 JS 堆为 30.34 MiB。平移重新挂载旧轮次，返回原位置保持相同身份，缩略图始终包含全部会话与轮次。

## 复现

在没有开发服务的独立 checkout 中执行：

```sh
npm run build
npm run test:waygoal-memory
```

结果位于 `test-results/waygoal/memory/profile.json`。配置与其他验证入口见 [开发指南](../development.md#长会话性能)。本次另通过 63 项连续聊天与分叉浏览器检查、12 项导航检查、26 项相关单元测试、类型检查和改动文件 lint。
