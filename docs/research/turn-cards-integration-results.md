# 连续聊天与真实 Pi 轮次接入

2026-09-15。接入依据是 [ADR 0006](../adr/0006-continuous-chat-and-turn-cards.md) 和[交互基线](../design/canvas-navigation-and-states.md)，原型分支没有整体合并。

## 改变的体验

服务于“保持方向”：右侧沿用 ChatWindow、ChatInput、快捷节点导航和 Pi 运行能力；左侧展示会话的轮次树。点击当前路径卡片定位原文，其他路径在画布内预览。切回总画布可以继续整理会话、分组与票据，当前聊天仍保留。

Tree 和消息编辑共用 Waygoal 的明确路径切换入口。切换成功后恢复该路径的文字、图片与待发送引用；失败或取消不替换当前聊天。助手消息的分叉包含该消息，用户消息的分叉从其 parent 开始，并将原文交回输入框。会话间继续也由用户明确选择。

## 真实来源与展示

- `lib/waygoal/turns.ts` 投影未压缩的 Pi entries，身份使用 session ID 与原始 entry ID。编号只用于展示，不承担身份。用户消息开始轮次，工具过程归入同轮；压缩和分支摘要分别显示。回答中再次分叉时，新路径显示延续卡片，不拼接兄弟路径的回答。
- 历史读取仍走宿主 context 接口，支持多页定位及压缩前原文。模型有效上下文另由 Pi 的 `buildContextEntries` 决定，两者不混用。
- Pi `0.85.1` 在 `message_end` 通知之后同步追加记录。宿主保留原事件顺序，随后补发该消息对应的 entry ID，使运行中已经保存的用户消息也能定位。
- 轮次位置、手动关联和独立预览位置保存在原有画布记录中。聊天仍使用 Pi 会话文件，不为卡片创建会话或票据。

## 引用范围与发送

本版明确提供整轮文字、最终回答、用户消息、完整路径文字及回答原文摘录。文字范围包含可见的工具结果文字，但不包含图片、思考内容和工具调用参数；界面在选择时说明范围，不生成这些内容的替代描述。需要图片时继续使用原有聊天附件能力。

材料在用户选取时读取并冻结。审阅区显示实际发送的原文；发送经过原有 prompt 通道，用户消息同时保留材料文字及 session、entry、范围和取得时间。后续改选不会修改旧消息。相同会话有效上下文已有的条目不重复加入；被压缩掉的原文可重新引用。跨会话复制的 entry ID 不猜测为同一来源。重叠材料在审阅区去重，预览和实际发送使用同一份结果。

读取材料期间开始发送、切换路径或离开当前聊天，会取消尚未完成的读取，过期响应不进入其他路径草稿。材料准备后若实际继续位置改变，宿主拒绝使用过期位置发送，保留输入，提示重新选择。普通聊天不要求选择材料；“仅作关联”不进入 prompt。

## 验证入口

- `npm run check`：静态检查、类型及全部单元测试。
- `npm --prefix apps/web run test:waygoal-branches`：连续聊天、双向定位、分支预览、Tree 草稿恢复、材料实际发送、真实分叉及窄屏检查。
- `npm run test:e2e`：全部 Waygoal 浏览器回归，包括原有票据、目录、多画布、分组与来源能力。
- 本轮截图与检查结果位于 `apps/web/test-results/waygoal/turns/`；它们是隔离宿主与可控假模型的结果，不覆盖旧研究图片。

## 本次验证结果

在 Node.js 24.21.0、Pi SDK 0.85.1 下：

- 静态检查及类型检查通过；单元测试 1,101 项通过。lint 仅保留未改动的旧实验文件中的 unused variable 警告。
- `npm run build` 生产构建通过；未改动的会话导出路由保留动态依赖编译警告。
- Waygoal 全部 10 组浏览器检查累计 248 项通过，其中连续聊天接入 26 项。前 8 组由整套命令完成；地图组修正实际导航入口后，与远程组分别复跑通过。
- 定向回归覆盖 300 轮历史跨多页定位、发送后保留已加载 DOM、慢回复期间定位、空会话分叉、两条路径的文字与材料草稿往返，以及延迟材料响应不串入新路径。
- Standards 与 Spec 两轴审查提出的问题均已修复并复核；桌面与窄屏截图已查看。材料只使用可控假模型验证实际请求，不据此声称真实供应商体验已验收。

## 使用范围

沿用进程内 Pi 宿主及原有会话写入限制。本轮模型调用使用隔离数据和可控假模型，没有使用个人现有会话或付费模型。输入草稿沿用宿主浏览器内存的保存方式；页面刷新后的草稿恢复不在本轮承诺中。发送后的引用来源及布局可重新读取。超大树的虚拟化、图片材料引用和视觉参数仍需真实日常使用验证。总画布沿用的多地图提示可能遮住另一张票据及其附属按钮；键盘聚焦后按 Enter 及已打开票据的面板入口可用，本轮未调整该提示布局。地图内容回归因此使用真实键盘入口，不代表重叠已修复。
