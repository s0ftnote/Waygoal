# 选文探索、材料托盘与多选综合接入

本轮由 ThoughtDAG 借鉴研究进入实现，服务于“理清想法、保持方向、推进与验证”。延续 Pi 作为真实会话与执行来源，不创建第二套运行器；不自动生成决定、重放下游或删除原讨论。

## 已接入

1. **聊天选文 → 分叉探索**：复用宿主的选文提问框，用户发送才调用 `fork_branch`，准确包含选中的已保存回答，不含其后的主线讨论。原会话、草稿和待发送材料保留；取消不创建会话。跨消息选区及没有保存身份的回答不提供分叉来源。正文支持指针及键盘扩选触发。
2. **材料托盘**：显示可读会话／问题、范围、份数和原文字符量，保留详情、来源 ID 与取得时间。查看来源只读定位画布或打开预览，不替换右侧聊天；来源失败仍保留快照。列表限高并可滚动，标题在滚动时保留，移除后键盘焦点不会掉入页面空白。
3. **多选轮次 → 加入材料，继续综合**：支持菜单点选模式与平台快捷点选，材料范围为回答、用户消息或整轮文字。读取并核对所有来源及目标路径后一次性加入；失败保留选区，取消、切路径、切会话和忙碌状态使旧请求失效。不覆盖草稿，不自动发送；用户在原输入框写综合目的后正常发送，真实轮次保存引用原文及来源。
4. **发送确认的竞态保护**：旧会话请求在切换后才返回时，仅消耗它实际提交的快照实例及其停放副本，不清空当前托盘。另一次重新取得的材料，即便来源 ID 相同，也不被旧响应移除。
5. **Review 后的异步边界**：旧回源不覆盖新导航，迟到材料不抢其他输入焦点；分叉载入失败重试复用真实 ID，离开发起位置后不跳回或自动发送，已输入的新草稿与恢复问题合并。后台注册不更改工作区当前画布；关闭流式选文浮层不会同时停止生成。具体问题与修复见[Review 记录](exploration-review-results.md)。

界面参数继续复用现有 Waygoal token 和反馈动效。宿主的其他选文入口保持原标签；Waygoal 定制标签和浮层主题显式传入。已有用户未提交的入口／聊天布局调整保留。

## 验证

- Node.js **24.21.0**，`npm run check` 通过：类型检查、lint（零错误，历史实验脚本仍有一个未使用变量警告）、**1143 项单元测试**。
- `test:waygoal-exploration`：**28 项浏览器检查**，真实 Pi SDK 与临时会话文件，配受控假模型；包含可见但尚未保存的流式选文及 Escape 边界。
- `test:waygoal-review`：五个故障注入场景，**30 项浏览器检查**；回源、焦点、离开画布、重试及提前打开分叉的竞态均先失败后通过。
- `test:waygoal-branches`：**59 项连续聊天／分叉／引用回归检查**，包括 DOM 连续性、草稿与路径恢复、引用快照、长历史、退出反馈和窄屏。
- `test:waygoal-workspaces`：**27 项工作目录／画布检查**，包括切换、记忆、重启、导入和归属隔离。四组共 **144 项浏览器检查**。
- 独立副本的生产构建通过。沿用宿主会话导出路由的动态依赖警告，未修改该路由；构建时清除继承的 `TURBOPACK` 并设置 `NODE_ENV=production`，不混用当前服务的开发环境。
- 桌面与窄屏截图覆盖多选、托盘和选文提问框；窄屏检查页面无意外横向溢出。视觉已按现有设计核对，不将桌面浏览器模拟当作真机触屏验收。

新增套件特别验证：

- 选文取消没有新会话、没有 Agent 命令，主线草稿和材料不变。
- 选文发送准确从所选 assistant entry 分叉；首次发送被明确拒绝后恢复输入，重试仍只有一个分叉。
- 多选读取失败不留下半份成功结果；路径切换后的迟到读取不污染新草稿。
- 只读回源前后活动 Pi 路径、会话文件、草稿与聊天输入 DOM 均不变。
- 分叉请求的成功响应被刻意延迟到回到主线之后，主线托盘仍保留。
- 综合请求真正包含两份所审阅原文，来源身份和发送快照可重载，原始来源会话不被改写。

为不中断正在运行的用户服务，浏览器与构建使用 `/tmp/waygoal-exploration-check` 独立副本、独立依赖副本、临时工作目录及 Pi 数据。没有重启用户的 30142 服务，没有使用用户实际会话发测试请求。测试命令需清除会改变宿主默认设置的 `WAYGOAL=1` 继承环境（单元测试），并使用 Node 24；浏览器套件自行显式开启 Waygoal。

证据复制至默认忽略目录 `apps/web/test-results/waygoal/exploration/`、`turns/`、`workspaces/`、`review-*/`，包含截图或 `checks.json`；红／绿执行日志位于 `review-logs/`。不覆盖历史研究截图。

## 仍未覆盖或未实现

- 未跑完整 14 组浏览器套件；本轮执行探索、竞态回归及受影响的连续聊天／分叉、工作目录／画布套件。
- 未使用付费真实模型或真实工具副作用做体验验收，复杂材料、长时间使用和真机触屏仍待验证。
- 未发送草稿与材料沿用现有内存恢复，不承诺刷新或重启恢复。已发送引用持久保存在 Pi 消息中。
- 多选是显式模式点选／快捷点选，不是矩形框选；综合目的使用当前输入框，不另设摘要运行器，也不自动创建新综合会话。
- 材料托盘不是完整请求预览，字符数不是 token；PDF 阅读闭环、正文搜索、来源版本比较仍为后续候选。
