# 轮次卡片与自由连线 · 可丢弃原型

2026-09-15。设计问题：**一轮问答成为一张卡片，用户从具体消息分叉，再手动连接不同卡片用于下一轮讨论，能否清楚理解来源、材料范围与发送时机？**

用户已认可探索的方向：轮次卡片、展开到具体消息、分叉、手动连线、跨路径组合。当前原型的具体布局和操作尚待用户试用；不代表真实 Pi 接入已完成。

## 可以试什么

- 卡片默认呈现一轮提问与回答；展开原文后，可从用户消息或 Agent 回答处分别分叉。
- 拖卡片标题移动；拖空白平移；使用缩放或“看全图”。窄屏首次聚焦当前卡片，详情在画布下方。
- 从已发送卡片右侧圆点拖向目标，或先点起点再点目标，建立引用。目标须是待发送讨论。
- 引用范围可选这一轮、只引用回答、只引用用户消息、到这里的完整路径，或从回答原文选取摘录。
- 查看发送材料后模拟发送。共同来源按样例消息身份去重；已发送材料固定，再分叉时保留这份材料。
- “仅作关联”只记录有关，不参与材料组合。右侧可取消关联或移除尚未发送的引用。
- 底部三个演练会实际驱动同一状态：组合两轮、从原话分叉、连线边界。切换演练重置样例。

## 与现有设计的关系

这是对先前设计方向的扩展：从会话卡片进入到轮次卡片，同时在“手动关联”之外试验用户显式选择的“引用并继续”。现有手动关联仍只负责整理。展示和回看依然不发送消息；引用先进入草稿，明确发送才产生下一轮。

原文卡片直接呈现已有对话，没有由模型重新拆解为问题卡，没有为每轮新建票据。Pi 原始树与用户选择的材料关系在产品接入时需要分别保留。
