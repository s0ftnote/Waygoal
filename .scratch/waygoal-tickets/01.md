## What to build

本地启动 Waygoal，以 Pi extension 接入现有运行能力；在一个普通工作目录的默认画布中找到已有会话、新开聊天、移动节点，并在重启后找回。

## Acceptance criteria

- [ ] 通过一个明确的本地启动入口打开画布；复用现有 Web 宿主及其进程内 Pi extension、Pi 认证、模型、工具和会话能力，不要求 Git 仓库、GitHub、Matt skills 或 tracker。本票不另建由已安装 extension 拉起 Web 进程的启动器。
- [ ] 已有 Pi 会话按真实身份登记到默认画布，展示已存标题或原有内容回退；重复发现不产生重复节点。新开独立会话能发送并显示真实 Pi 消息和运行状态。
- [ ] 用户可以使用已安装 skills，缺少 skill 时给出明确反馈；没有固定 Wayfinder 根入口、额外工作流提示或自动路由。
- [ ] 节点可拖动、画布可平移缩放。画布记录与插件代码分离，使用 Pi 实际数据目录；从一开始按工作目录隔离身份、位置和最近查看位置，刷新和宿主重启可恢复，恢复不自动发消息。
- [ ] 先复用现有普通会话的新建、发送和读取能力，仅做本票所需的窄范围改造；票据入口的旧行为留到票据讨论接入时替换，不先建设通用插件框架。
- [ ] 扩展已有隔离 Pi 存储并启动独立宿主的浏览器验证骨架，补上可控模型输出与发送验证，从真实界面检查发现、新建、明确发送、消息呈现和重启恢复；采用已确认主题，窄屏有返回画布入口，基本操作键盘可达。
