# 分出去，再接回来 · 一次有界实验

日期：2026-09-09。问题：从主讨论分出一个设备核对会话，结束后能否带着结论接回原来的场地问题？如果期间预算改变，旧交接信息会不会覆盖新条件？

## 直接体验

打开本目录的 `index.html`。这是单文件 HTML，无需安装或联网；在仓库根运行 `npm run prototype:canvas` 后也可访问 http://127.0.0.1:30145/return-to-thread/index.html 。页面有自由操作和四条引导路径：正常往返、预算变化、未完成就返回、重复返回。

界面是可交互回放，按钮不调用模型。显示的模型回复来自本次真实 Pi SDK / gpt-5.6-luna 试跑；方案草稿、页面状态和依据展开是固定样例上的交互演示。

## 样例与结果

所有价格、场地、人数和预算均为虚构夹具，不是用户实际决定或外部研究结果。主会话已知 8 人、预算 1000 元、饮料 300 元；小画室场租 400 元，咖啡馆 550 元。独立子会话额外拿到设备事实：小画室可遮光，整套设备 200 元；咖啡馆设备免费但无法遮光。

实际调用产生五条回复，原始提示、输出、会话条目和模型标识在 `evidence.json`：

1. 主讨论先留下设备核对后的继续问题。
2. 子会话独立给出设备事实，不决定选哪个场地。
3. 对照分支只收到“设备分支已经聊完”：模型明确缺少核对结果，无法完成比较。
4. 同一原始父会话收到有来源的报告和返回问题：模型算出小画室 900 元可行，咖啡馆遮光不符；没有声称用户已接受。
5. 从相同父上下文复制的另一个分支收到最新预算 800 元和旧预算为 1000 元的交接信息：模型按 800 元判断，两者均不可行。

正常返回的父会话 ID 前后相同：`01a0845a-3594-743c-af05-f9cd7de00405`。子会话为 `01a0845a-52ce-743c-af05-f9d3b83011d9`。会话在内存中运行，条目只作为实验资料写到本目录；没有改 Pi 全局模型设置或原有示例票据。

## 学到什么

- 导航位置与知识交接是两件事。单纯切回原会话，不会让独立子会话的结果自动进入当前上下文。
- 返回关系至少包含原会话、出发消息、分支结果来源以及回来要继续的问题。它不同于“票据 A 阻塞票据 B”。
- 带回的是事实和结论，不是冻结的整个旧上下文。新的预算优先，设备事实仍可保留。
- 回看原讨论可以早于分支完成；这不代表问题已经解决。报告带回与重复导航需要分开记录。

## 证据的边界

这是一次受控的会话交接实验，不是可靠性统计。已核对全部五条模型输出，并在浏览器走过四条路径，检查了 390px 移动布局；截图为 `normal.png`、`changed.png`、`mobile.png`。

本实验没有加载 Wayfinder 或其他 skills，没有 tracker 读写、真实研究、Agent 自动建图、并发修改、重启恢复、自动影响分析或真实用户接受。交接对象和返回位置由实验代码构造，尚未验证 Agent 能自动选择正确的范围和来源。

尤其不能据此推断 `/wayfinder #票据` 无法获取其他票据结论：它本来就可以按需读取关联票据。这里的对照只测了没有工具的独立会话是否自动共享上下文。

单文件界面在预算变化时更新演示判断，尚未接入实际地图变更。它能帮助用户判断“回来接着聊”和“从方案回看依据”是否自然；设计认可仍待用户体验。未把演示状态机合入真实业务。
